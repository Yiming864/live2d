# 调参手册（= 标准品的标定记录）

每个系数：在哪、现值、调大/调小意味着什么。改完必须重跑：

```
node scripts/check_avatar.mjs <皮套目录>
```

全部 PASS 才能交付。数值单位：px（1024 画布基准；别的分辨率按 S=宽/1024 缩放）。

## 生成器推导的值（在 `<皮套>/src/rig.js` 的 GEO）

| 字段 | 标准品值 | 含义 / 调整方向 |
|---|---|---|
| `pivot` | (512, 470) | 头部枢轴=脖子根。偏高→点头时下巴跟得少；偏低→整头平移感 |
| `pivotNorm` | 420 | pivotDist 归一化。调小→离枢轴远的部位视差更大 |
| `head.top/fadeSpan` | 120/210 | 颅顶衰减起点/跨度。想让颅顶更"硬"（更球）：top 调小或 fadeSpan 调大 |
| `pitch.rx/ry` | 180/235 | 点头平坦区椭圆。**必须盖住脸层四角**（角点 r<1）——165/210 时角点在椭圆外，点头脸内剪切、网格接缝显形成"三角形的线"（用户实测） |
| `sil.rx/ry` | 132/168 | 头发外轮廓反向椭圆。前外发错开成"两道轮廓"→调小 |
| `body.hemY/fall` | 900/500 | 躯干圆柱：下摆固定线/过渡。下摆跟着动→hemY 调大 |
| `neck.y0/span/drop/base` | 540/160/0.68/0.9 | 脖子：可见段**近刚体 0.9**（点头不伸缩，-6%→-0.16%），过渡带起点必须在**脖子下缘以下**（脸底+0.24 脸高），终点藏衣领下。**必须 smoothstep**（线性斜坡末端导数突变=可见折点）。另：上衣 z 必须压在脖子上（PSD 原序），脖子下端才滑进衣领下面 |
| `collar.*` | 500/420/0.42/0.36 | 衣领跟随。领口露出脖子→base 调大 |
| `src` | (140,0,760,900) | 取景框。h 到 hemY 为止是故意的（裁掉静止的下摆） |

## deformer.js（写死的动作系数）

| 系数 | 值 | 含义 |
|---|---|---|
| `squeezeFar/squeezeNear` | 0.16/0.01 | 转头非对称内收。0.22="横向过度压缩"；0.13="眼睛嘴变化没了"；0.19="轮廓变化偏大"。**别偏离 0.15~0.18** |
| yaw 整体平移 | `yawAmt*34` | 转头位移主体。**≈rigkit 标定 31px×1.1，勿超**——52px 时脸滑出脖子覆盖范围，"脑袋跟脖子脱节"（用户实测）。幅度不够优先调 squeezeFar 而不是行程 |
| 点头位移场 | **穹顶场**（rigkit pitch_profile 同构） | 椭圆**贴合脸部**（半轴≈脸半轴×1.05）；中心 Q≈1.0、额侧 0.45、下颌侧 0.60——五官领先轮廓，头有透视形变。⚠ 纯平移=头不动只剩脖子动（"伸缩脖子"）；⚠ 椭圆别放大到盖住四角（那是平移方案的要求，穹顶场下会让头又不动了）；衰减带 r_sil=2.0，脸颊角不翻负（否则脸上出三角形接缝） |
| 点头行程 | 上 24 / 下 18 | 上下不对称（标定 22.5/16）：低头被遮挡多、行程小 |
| pitchGain | topwear 0.08 / neck 0.45 | 点头不传给躯干（不耸肩）；脖子跟 45%，下颌滑动藏在脸下 |
| **yawGain** | neck **函数**：顶部 0.55→根部 0.10；topwear/collar 0.1（其余 1） | 摇头时脖子是**弯**的：顶部贴着下颌走（衔接不断），根部锚在躯干上。⚠ 演变史：全跟=“脖子位移”；全 0=“头脖脱节”。⚠ topwear 与 topwear_collar 必须同值 |
| PITCH_LIMIT_DEG | 16 | 点头限幅（tracking.js）。超 ±16° 停止跟踪（yaw ±30） |
| neck `bottomFade` | 0.72 | 脖子下端渐隐进衣领（"插进衣领里"）。**上衣必须在脖子下面**（z 更小）——see-through 高领在 topwear 里很高，上衣压脖子会整段盖住脖子（用户实测） |
| 头发轮廓反向 | `nx -= yawAmt*13*out` | 纸片感对策之一。调大→外发滞后更明显 |
| BodyWarp 身体 | `bx*30`，跟随 1/3 | 身体跟随头部 1/3 幅度+滞后（main.js bodyFollow）。"头在静止身体上滑"=身体没跟上 |
| `LIMIT_DEG` | 30 | 姿态限幅（tracking.js）。超 ±30° 停止追踪是**故意的** |
| EyeWarp `lidLine` | `H*0.67` | 闭眼锚点。生成器按它标 lashSplit/Drop；改它必须同步 lash 系数 |

## rigid / feature（rig.js 图层定义）

| 部件 | rigid | 说明 |
|---|---|---|
| face | 1 | 曲面本身 |
| eyebrow/eyelash/eyewhite/mouth | 0.5 | 五官自身形变减半 |
| nose | 0.45 | 硬凸起 |
| irides | 0.4 | 圆盘最硬 |
| ears | 0.7 | 有厚度 |
| earwear | 0.35 | 金属吊坠 |

`feature: true` = 五官整体移动（中心位移+打折的位移梯度）→ 锁死五官相对距离。
**yawDepth 只作记录，不参与位移**——"凸出部位多挪"的横向偏移实测无可见收益却让五官脱离脸，已置零（`nx += yawAmt*depth*0`）。别再打开。

## 三个已经踩过的实现坑（改 deformer 前必读）

1. **雅可比是"位移场"的**：`J = ∂D/∂x`，不是位置映射 `∂(x+D)/∂x`。漏减单位矩阵 ⇒ 五官被缩到 rigid 倍（虹膜面积只剩 13.5%，脸上白条纹）。
2. **局部动作必须先于曲面执行**：局部变形器都在静止坐标系写（EarRingSway 用 `y−meta.y` 当摆长），先曲面后局部 ⇒ 抬头时耳坠塌成一个点。
3. **局部动作拆「平移+形变」**：整个塞进被 rigid 打折的 q ⇒ 注视 18px→7.2px（眼睛不转）；整个加在仿射后 ⇒ 眨眼被撑回一半（眼闭不上）。正确式：
   `v = centre + d0 + rigid·(q·J) + lt`，其中 `q = (局部动作后的点 − lt) − centre`。

## 眨眼 / 口型机制（标准品做法，skill 逐字复刻）

**眨眼**（三层配合，无变体图）：
1. 开合度 = blendshape × 几何 EAR **取更强闭合信号**（blendshape 在侧脸/低头
   常低估到 0.4~0.6，几何 EAR=上下睑距÷眼宽 兜底——否则"人闭眼皮套没闭"）
2. 眼白/虹膜：以闭合线为锚压缩 + 淡出（开合度 0.28→0.10 全隐）
3. **上睫毛几何下落**（lashDrop=0.30×H，smoothstep 权重，落在闭合线上）
4. **下睫毛+眼睑阴影淡出**（lashSplit=0.62H 分界，按三角形重心取值）
   → 闭眼 = 一条干净的闭合线，无稳态双睫毛

**口型**（几何缩放，无变体图）：
- `sy = 0.22 + 1.35×mouthOpen`（以**静止中心**为基准——注意它也会缩放
  头部传来的位移，所以渲染顺序必须"先局部动作、后曲面"）
- 嘴角按 mouthForm 上扬，大笑叠加加宽
- **拉伸轴跟随头部 roll**：局部坐标先反转 roll、缩放、再转回——否则歪头
  (roll −0.77) 时张嘴，两角 y 差 3.3→24.5px（表观倾斜放大 16°，"歪嘴"）。
  同理适用于任何"沿局部轴的形变"（未来加眯眼/鼓腮等都要过这一步）

**头部动作**：pitch=穹顶场（中心 1.0/额侧 0.45/下颌 0.60，行程上 24/下 18）、
yaw=平移 34+非对称内收 0.16+轮廓反推、roll 刚体；脖/领 yawGain=0（弯/锚），
pitchGain 0.45/0.08（不耸肩不伸缩）；±30°/±16° 限幅；出画保持 3 秒。

## 检查器判据（check_avatar.mjs，与标准品同口径）

- 五官绝对尺寸比 ≈1（曾"全绿但眼睛缩成 4 成"——相对比较测不出恒定缩放，必须测绝对值）
- 四边形面积比 >0.4（嘴 0.30 是设计值：静止 sy=0.22+1.35×0.06）
- 点头脸高 <2%；五官间距 <5%；转头远侧内收 >6% 近侧 >−3%；整脸宽 4~12%（默认表情基线）
- 眨眼闭合 <15%、张嘴 >1.5×、注视 >8px；脖子权重二阶差分 <0.001
